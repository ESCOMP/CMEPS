======================================
Configuring and running a case (UFS)
======================================

.. note::

   **This section is to be filled in.**

This page will describe how a UFS case is configured and run, the counterpart to
the CESM/NorESM :ref:`Configuring and running a case (CESM/NorESM)
<running-a-case>` page.

Unlike CESM/NorESM, UFS does not use the CIME case-control system, so the build
and run workflow — and how the coupling intervals, run sequence and run
configuration are produced — differ. *This workflow remains to be documented
here.*
